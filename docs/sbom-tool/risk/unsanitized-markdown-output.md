
# untrusted text reaches markdown reports unsanitized (Risk)
## Description
Component names, license names/URLs and advisory text from SBOMs and APIs are written into markdown with only | and newlines escaped.


## Documentation
### Description

adapter.report.markdown/md-escape escapes only the pipe and newlines. format-license-name builds a link from the license URL, which adapter.sbom.cdx takes unchecked from the SBOM. Advisory summaries and ids from the external services are rendered as well. Found in the security assessment at commit 5279795; confidence high.

### Impact

A crafted SBOM can inject links (any URL scheme) or break the report structure. The effect depends on where the markdown is rendered, e.g. a CI summary, a wiki or a PR comment.

### Mitigation

Escape markdown metacharacters in labels and allow only http and https URLs (see requirement safe-report-output). Not started.
