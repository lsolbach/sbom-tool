
# VEX conflict resolution may be too coarse (Risk)
## Description
The most conservative status always wins, so a supplier's later, corrected not-affected statement can never override an older affected one.


## Documentation
### Description

Decision vex-most-conservative-status-wins was chosen for safety and simplicity, and the OpenVEX specification mandates no resolution strategy.

### Impact

False positives that cannot be suppressed when several suppliers' documents conflict.

### Mitigation

Revisit if real multi-supplier conflicts occur, e.g. by weighing statement timestamps. Changing it is tier 3.
