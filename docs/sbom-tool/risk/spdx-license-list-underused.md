
# SPDX license list not used as the source of truth (Risk)
## Description
Identifiability is decided by a LicenseRef- prefix heuristic, and the list's deprecated flag is read but not reported.


## Tags
technical debt

## Documentation
### Description

domain.license/spdx-identifiable? treats every id without a LicenseRef- prefix as resolvable, so an unknown or misspelled id counts as identified. adapter.license.spdx reads :deprecated? for every license, but no report uses it. The list is a local file or a bundled snapshot, never refreshed at runtime.

### Impact

Wrong or deprecated license ids are not flagged distinctly, so license reports may overstate how many components are identified.

### Mitigation

Open ideas in dev/ideas.md (SPDX Licenses).
