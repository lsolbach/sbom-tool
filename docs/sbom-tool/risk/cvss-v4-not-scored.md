
# CVSS v4 vectors are not scored (Risk)
## Description
Only CVSS v2 and v3 are parsed, so findings that carry only a v4 vector rate as :unknown.


## Documentation
### Description

domain.cvss supports v2 and v3. The v4 parser is only a proposal (dev/plans/cvss-v4-vector-parser.md).

### Impact

Vulnerabilities rated only by a v4 vector can fall under unknown severity in reports and policy decisions.

### Mitigation

Implement the proposed v4 parser.
