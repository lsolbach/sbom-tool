
# bounded-pmap duplicated in three adapters (Risk)
## Description
The same fixed-thread-pool helper is copied into the osv, deps-dev and github-advisory adapters, so a fix must be applied three times.


## Tags
technical debt

## Documentation
### Description

adapter.vulnerability.osv, deps-dev and github-advisory each define a private bounded-pmap. The plans chose to duplicate it locally rather than share it (dev/plans/osv-vulnerability-adapter.md). A shared helper would need a home that adapters may depend on without breaking the layering, e.g. a small utility namespace.

### Impact

Divergent fixes and behavior between adapters, and each future adapter (e.g. NVD) adds a fourth copy.

### Mitigation

Extract one shared helper. Not started.
