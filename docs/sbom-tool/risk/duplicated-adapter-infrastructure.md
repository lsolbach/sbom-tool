
# vulnerability adapters duplicate their HTTP infrastructure (Risk)
## Description
osv, deps-dev and github-advisory each carry their own HTTP client, request and error handling, API-key file reader, warn and bounded-pmap.


## Tags
technical debt

## Documentation
### Description

Beyond bounded-pmap and warn (see duplicated-bounded-pmap and duplicated-warn-helpers), the three adapters repeat the HttpClient setup, the send and error-tagging pattern, the API-key file and environment lookup and the JsonProcessingException Class/forName workaround. Found in the architecture assessment at commit 5279795; confidence high.

### Impact

Each cross-cutting fix has to be made three times, and a fourth adapter (NVD) adds a copy. This includes the open security fixes (no-network-timeouts-or-size-limits, pagination-url-not-pinned-to-host, debug-println-to-stdout).

### Mitigation

Proposed decision shared-adapter-support: one adapter-internal support namespace. Not started.
