
# real network calls are not covered by the automated tests (Risk)
## Description
The vulnerability adapters' HTTP calls are deliberately not exercised by bb test, so API changes surface only in real use.


## Documentation
### Description

The plans keep the real query and fetch calls out of the test suite to keep tests offline and deterministic. Mapping and chunking logic is covered, the transport is not.

### Impact

Changes in the OSV, deps.dev or GitHub responses or limits are noticed late.

### Mitigation

An opt-in integration test or a periodic manual check. Not defined.
