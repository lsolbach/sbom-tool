
# failed vulnerability lookup is indistinguishable from no findings (Risk)
## Description
A failed live lookup only warns on stderr and yields no vulnerabilities, so --fail-on-violations can pass on incomplete data.


## Documentation
### Description

Live lookups are fail-soft by decision (opt-in-fail-soft-live-lookup, failure-policy-by-input-kind). The report and the exit status carry no trace of a degraded lookup.

### Impact

A CI gate can report success although a vulnerability source was unreachable. This matters most for the goal ci-gate.

### Mitigation

Open idea in dev/ideas.md ('Vulnerability Database Adapters'): treat lookup errors differently from an empty result, e.g. in the report and as a distinct or opt-in strict exit code (a public contract, so tier 3).
