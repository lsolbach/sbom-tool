
# share the adapters' HTTP infrastructure in adapter.http and general helpers in util (Decision)
## Description
The osv, deps-dev and github-advisory adapters share one HTTP namespace (adapter.http) and general helpers in the util folder for key reading, bounded concurrency and warnings.


## Tags
solution strategy

## Documentation
### Status

Accepted.

### Context

The vulnerability adapters (osv, deps-dev, github-advisory) all need the same HTTP client with timeouts and a response size limit, host-pinned requests, key-file reading, bounded concurrency and diagnostics on stderr. These concerns are cross-cutting (requirements bounded-network-calls and credentials-only-to-own-service) and would otherwise be implemented and fixed once per adapter. Layering is decided in clean-architecture-layering.

### Options

1. Do nothing: keep three copies and fix each one.
2. Shared code inside the adapter layer, used by the vulnerability adapters: the HTTP code in one namespace (adapter.http) and the general helpers in namespaces in a util folder.
3. Move the helpers into the application layer.

### Decision

Option 2. adapter.http sets the timeouts and the response size limit and keeps credentials to their own host. The general helpers (key file reading, bounded concurrency, URL encoding, diagnostics on stderr) live in namespaces in the util folder (src/sbom_tool/util), initially one namespace, util.functions. Option 3 is rejected: the helpers are I/O and belong in the adapter layer. Option 1 is cheapest at first but multiplies every fix and every new adapter.

### Consequences

Benefits: one fix point, smaller adapters, a consistent failure mode (a timeout becomes a failed lookup). Costs: adapter namespaces may now depend on each other as long as no cycle is introduced, and the util folder is a new place whose namespaces are leaves (depend on no other project namespace) and may be used from any layer; both rules are stated in AGENTS.md. It supersedes the duplication stated in the consequences of bounded-concurrent-lookups. Reversible. Babashka compatibility must be kept (requirement jvm-and-babashka-portability).

### Evidence

adapter/http.clj, util/functions.clj and their tests; dev/plans/shared-adapter-support.md.
