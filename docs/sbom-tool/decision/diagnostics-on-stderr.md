
# write reports to stdout and all diagnostics to stderr, without a logging library (Decision)
## Description
Warnings and error messages go to *err* as plain 'Warning: ...' lines from small per-adapter helpers; stdout carries only the report.


## Tags
crosscutting concept

## Documentation
### Context

Reports are consumed by pipes and files, so diagnostics must not corrupt them. The tool is a short-lived CLI without long-running operations.

### Options

1. A logging library with levels and appenders. 2. Plain writes to stderr. Option 1 is a reconstructed alternative.

### Decision

Option 2. There is no logger: adapters print 'Warning: ...' to *err*, the CLI prints error messages to *err*, and --debug only adds exception detail.

### Consequences

No dependency and no configuration, and report output stays machine-readable. There are no log levels, no structured logs and no verbosity switch besides --debug. The warn helper is duplicated in several adapters.

### Evidence

adapter/sbom/cdx.clj, spdx.clj, adapter/vex/openvex.clj, adapter/vulnerability/*.clj (private warn), adapter/ui/cli.clj.
