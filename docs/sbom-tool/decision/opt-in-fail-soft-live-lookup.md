
# make live vulnerability lookup opt-in and fail-soft (Decision)
## Description
The tool runs fully offline unless a vulnerability source is selected; a failed lookup warns on stderr and yields no additional vulnerabilities instead of aborting the run.


## Tags
solution strategy

## Documentation
Rationale: network flakiness on a resource the user did not directly name should not break a CI run. Consequence and open risk: a lookup failure is indistinguishable in the report from 'no additional vulnerabilities', so a --fail-on-violations gate can pass on incomplete data (see dev/ideas.md, 'Vulnerability Database Adapters'). Contrast with the VEX decision, where malformed user-supplied files fail loudly. Evidence: dev/plans/osv-, github-advisory- and deps-dev-vulnerability-adapter.md.
