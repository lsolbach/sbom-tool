
# untrusted input is handled as data (Requirement)
## Description
SBOM, VEX and policy files are parsed as data and never evaluated.


## Tags
quality

## Documentation
### Scenario

The tool reads an SBOM, VEX or policy file from an untrusted source.

### Measure

Input is parsed with data readers only. Malformed input produces a typed error, not a crash or code execution. Source: dev/plans/vex-openvex-adapter.md (VEX files are as user-controlled as SBOM files), AGENTS.md (security starting points). This has not been reviewed in the code yet.

### Quality attribute

Security.

| Decision | Description |
