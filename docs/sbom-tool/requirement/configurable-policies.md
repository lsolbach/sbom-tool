
# configurable policies (Requirement)
## Description
License and vulnerability policies are set in a policy file, not in code.


## Tags
quality

## Documentation
### Scenario

A team changes which licenses are whitelisted, greylisted or blacklisted, or which vulnerability severities block a build, by editing a policy file.

### Measure

No code change or rebuild is needed to change a policy. Source: AGENTS.md ("Policies must be configurable").

### Quality attribute

Flexibility.
