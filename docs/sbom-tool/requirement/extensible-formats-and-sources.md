
# extensible formats and sources (Requirement)
## Description
SBOM formats, policy formats, report formats and vulnerability sources can be added without changing the core.


## Tags
quality

## Documentation
### Scenario

A developer adds an SBOM format or version, a report format or a vulnerability source (e.g. NVD).

### Measure

The change consists of a new adapter namespace that registers with an existing multimethod; domain and application code stay unchanged. Source: AGENTS.md ("Other formats/versions could be added"), dev/plans/nvd-vulnerability-adapter.md.

### Quality attribute

Extensibility and modifiability.

## Implementing Decisions
| Decision | Description |
|---|---|
| [extend input and output formats through multimethod extension points](../../sbom-tool/decision/multimethod-extension-points.md) | The application layer defines multimethods (repository/read-sboms, read-policies, read-vulnerability-sources, template/render); adapters register formats and sources with defmethod, so the core knows neither formats nor I/O. |
