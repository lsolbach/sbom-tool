
# network calls are bounded in time and size (Requirement)
## Description
Every live lookup request has a connect and request timeout and a response size cap, and a timeout counts as a failed lookup.


## Tags
quality

## Documentation
### Scenario

A vulnerability service stalls, answers slowly or returns a huge body during a CI run.

### Measure

The run ends within a bounded time and memory use stays bounded. The timeout and size values are not defined yet and need a maintainer decision. Not met yet (see risk no-network-timeouts-or-size-limits).

### Quality attribute

Reliability and resource use, security (availability).
