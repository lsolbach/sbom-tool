
# network calls are bounded in time and size (Requirement)
## Description
Every live lookup request has a connect and request timeout and a response size cap, and a timeout counts as a failed lookup.


## Tags
quality

## Documentation
### Scenario

A vulnerability service stalls, answers slowly or returns a huge body during a CI run.

### Measure

The run ends within a bounded time and memory use stays bounded: 10 seconds to connect, 30 seconds per request and 20 MiB per response (maintainer decision), redirects are not followed. Met by adapter.http (see plan dev/plans/shared-adapter-support.md), verified by tests with a local server.

### Quality attribute

Reliability and resource use, security (availability).
