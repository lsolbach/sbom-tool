
# offline by default (Requirement)
## Description
The tool makes no network calls unless a live vulnerability source is explicitly selected.


## Tags
quality

## Documentation
### Scenario

A user or CI job runs the tool on SBOM files without -D/--vulnerability-source. Reports contain only what the SBOM and VEX files provide.

### Measure

No network access happens with the default option :none (verifiable by running without network access). Source: README ("fully offline"), dev/plans/deps-dev-vulnerability-adapter.md.

### Quality attribute

Security and privacy (no component data leaves the machine unasked), reliability in restricted CI networks.

## Implementing Decisions
| Decision | Description |
|---|---|
| [make live vulnerability lookup opt-in and fail-soft](../../sbom-tool/decision/opt-in-fail-soft-live-lookup.md) | The tool runs fully offline unless a vulnerability source is selected; a failed lookup warns on stderr and yields no additional vulnerabilities instead of aborting the run. |
