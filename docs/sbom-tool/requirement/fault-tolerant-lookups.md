
# lookup failures do not abort the run (Requirement)
## Description
A failed live lookup is reported as a warning and the remaining results are still produced.


## Tags
quality

## Documentation
### Scenario

A vulnerability service times out or returns an error for some components.

### Measure

The run completes with the data available. A failed chunk or id is dropped with a warning on stderr. The downside is recorded in the risk failed-lookup-looks-like-clean-result. Inferred from the code.

### Quality attribute

Reliability (fault tolerance).
