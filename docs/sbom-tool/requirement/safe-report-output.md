
# report output is safe to render (Requirement)
## Description
Untrusted text in reports is escaped for the output format, and only http(s) URLs become links.


## Tags
quality

## Documentation
### Scenario

A report built from an untrusted SBOM or from external service data is rendered in a CI summary, wiki or PR comment.

### Measure

Component names, license names and advisory text cannot add markup, and link targets with schemes other than http and https are not rendered as links. Verifiable with a test SBOM that carries markdown and javascript: URLs. Not met yet (see risk unsanitized-markdown-output).

### Quality attribute

Security (output integrity).
