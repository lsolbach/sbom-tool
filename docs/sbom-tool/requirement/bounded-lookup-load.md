
# bounded load on external services (Requirement)
## Description
Live lookups use batching and a fixed number of concurrent requests.


## Tags
quality

## Documentation
### Scenario

A large SBOM is looked up on OSV, deps.dev or the GitHub Advisory Database.

### Measure

The number of concurrent requests is bounded per adapter (fixed thread pool) and OSV requests are chunked. No time budget or concurrency target is defined, and the defaults are partly guesses (see risk external-service-limits). Inferred from the code.

### Quality attribute

Performance efficiency and resource use.
