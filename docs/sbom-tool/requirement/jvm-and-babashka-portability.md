
# runs on the JVM and under babashka (Requirement)
## Description
Source namespaces load and run identically as an uberjar on the JVM and under babashka.


## Tags
quality

## Documentation
### Scenario

The tool is started as a Leiningen uberjar or with the babashka launcher (bb.edn), and the tests run with bb test.

### Measure

The same sources work under both runtimes, so no dependency may be unavailable in babashka (e.g. no clj-http) and JVM-only classes need a workaround (the JsonProcessingException Class/forName fix). Source: dev/plans/deps-dev-vulnerability-adapter.md.

### Quality attribute

Portability.
